1. Какие действия в работе показывают прототипирование и 
итеративность?

Сначала создаётся простая форма и минимальное поведение (добавление имени), затем постепенно добавляются проверки ввода, кнопки удаления и очистки, полный журнал. Работа идёт шагами: сделать, проверить, улучшить.
 
2. Чем Visual Studio отличается от C#, .NET и Windows Forms? 

Visual Studio – среда разработки (редактор, конструктор форм, отладчик).
C# – язык программирования.
.NET – платформа и набор библиотек.
Windows Forms – библиотека для создания оконных приложений.

3. Чем проект отличается от решения и где находится папка вашей 
работы? 

Решение (файл .sln) – контейнер, который может содержать несколько проектов.
Проект (файл .csproj) – одно конкретное приложение.
Папка работы – та, в которой лежит файл решения .sln.

4. Для чего нужны Toolbox, Properties, Form Designer и Solution Explorer? 

Toolbox – панель элементов управления (кнопки, поля, списки).
Properties – свойства выбранного элемента.
Form Designer – визуальный конструктор формы.
Solution Explorer – дерево файлов проекта и решения.

5. Чем (Name) элемента отличается от его свойства Text? 

(Name) – имя элемента в коде (txtDriver, btnAdd).
Text – текст, который видит пользователь на экране.

6. Что такое класс Form1 и когда выполняется его конструктор? 

Form1 (или MainForm) – класс окна приложения.
Конструктор выполняется при создании формы, то есть в момент запуска приложения.

7. Зачем нужен InitializeComponent и почему его нельзя удалять? 

Метод InitializeComponent создаёт и настраивает все элементы, размещённые в конструкторе формы, без него форма будет пустой.

8. Чем событие Click отличается от обработчика btnAdd_Click? 

Click – событие (момент нажатия на кнопку).
btnAdd_Click – метод-обработчик, который выполняется в ответ на это событие.

9. Как создать обработчик и проверить его связь с кнопкой? 

Дважды щёлкнуть по кнопке в конструкторе, потом Visual Studio создаст метод обработчика.
Проверить связь можно в окне Properties, вкладка Events, Click.

10. Что означают string, int и bool? Чем = отличается от ==? 

string – текст (строка).
int – целое число.
bool – логическое значение (true / false).
= – присваивание значения.
== – сравнение на равенство.

11. Почему TextBox.Text нужно преобразовывать перед числовым 
сравнением? 

Свойство Text всегда имеет тип string. Чтобы сравнить его с числами (30 и 600), строку нужно преобразовать в int с помощью int.TryParse.

12. Что делает Trim и меняет ли он сам текст поля? 

Trim() убирает пробелы в начале и в конце строки.
Сам текст в поле ввода он не меняет. ОН возвращает новую строку.

13. Какие результаты возвращает int.TryParse и что означает out? 

int.TryParse возвращает true, если преобразование удалось, и false, если нет.
out – параметр, в который записывается полученное число, но если преобразование успешно.

14. Почему после ошибки нужен return и завершает ли он приложение? 

return прекращает выполнение текущего метода, чтобы не выполнять код дальше после ошибки.
Приложение при этом не закрывается.

15. Почему проверка выхода за границы использует ||, а не &&? 

Нужно среагировать, если время меньше 30 ИЛИ больше 600.
С оператором && условие почти никогда не выполнялось бы.

16. Что означает SelectedIndex = -1 и чем индекс отличается от Count? 

SelectedIndex = -1 означает, что ничего не выбрано.
Индекс – номер выбранного элемента (начиная с 0).
Count – общее количество элементов в списке.

17. Чем отличаются объявление ClearInput и его вызов? 

Объявление – написание самого метода (private void ClearInput() { ... }).
Вызов – использование метода в нужном месте: ClearInput();.

18. Почему очистка текущего ввода не должна очищать список 
результатов? 

Потому что пользователь хочет только сбросить поля для нового ввода, а уже добавленные записи должны остаться в списке.

19. Как с помощью точки останова посмотреть значение driver?

Поставить точку останова (клавиша F9) на нужной строке, запустить отладку (F5), когда выполнение остановится, навести курсор на переменную driver или посмотреть её значение в окне Locals.
 
20. Почему после повторного запуска результаты исчезают?

Потому что данные хранятся только в оперативной памяти. При закрытии приложения они теряются.
